## 1. 서비스 개요

### 1.1 서비스 정의

| 항목 | 내용 |
|------|------|
| **서비스명** | 에대숲 (Czakuan) |
| **서비스 유형** | 커뮤니티 플랫폼 |
| **타겟 사용자** | 에버랜드 캐스트(직원) 및 주변 상권 종사자 |
| **운영 환경** | 웹 (모바일 반응형), PWA 지원 |

### 1.2 서비스 URL

| 환경 | URL |
|------|-----|
| 테스트 서버 | https://test.czakuan.com |
| 운영 서버 | https://www.czakuan.com |

### 1.3 핵심 가치

1. **익명성 보장**: 민감한 주제에 대해 자유롭게 소통할 수 있는 익명 게시판 제공
2. **커뮤니티 형성**: 에버랜드 관련 종사자들 간의 정보 공유 및 소통 창구
3. **접근성**: 카카오 소셜 로그인으로 간편한 가입/로그인
4. **비공개 소통**: 특정 게시판에서 비공개 댓글을 통한 1:1 소통 지원

## 2. 사용자 정의 및 권한 체계

| 역할 | 코드명 | 설명 |

## 3. 기능 요구사항

### 3.1 인증 시스템

#### 3.1.1 회원가입

| 항목 | 상세 |
|------|------|
| **가입 방식** | 카카오 소셜 로그인 전용 |
| **필수 입력** | 닉네임 (카카오 연동 후 입력) |
| **닉네임 규칙** | 중복 불가, 고유해야 함 |
| **가입 프로세스** | 카카오 인증 → 닉네임 입력 → 가입 완료 |

**회원가입 플로우:**
```
1. 사용자가 "카카오로 시작하기" 클릭
2. 카카오 로그인 페이지로 리다이렉트
3. 카카오 인증 완료 후 콜백 페이지로 이동
4. 신규 사용자인 경우 닉네임 입력 화면 표시
5. 닉네임 입력 및 중복 확인
6. 회원가입 완료 → 메인 페이지 이동
```

#### 3.1.2 로그인

| 항목 | 상세 |
|------|------|
| **로그인 방식** | 카카오 소셜 로그인 |
| **자동 로그인** | 선택 옵션 제공 |
| **세션 유지** | Access Token (1분) + Refresh Token (7일) |

**로그인 플로우:**
```
1. 사용자가 "카카오로 로그인" 클릭
2. 카카오 로그인 페이지로 리다이렉트
3. 카카오 인증 완료 후 콜백 페이지로 이동
4. 기존 사용자인 경우 토큰 발급
5. 메인 페이지로 이동
```

#### 3.1.3 로그아웃

| 항목 | 상세 |
|------|------|
| **로그아웃 처리** | 토큰 삭제 (쿠키에서 제거) |
| **리다이렉트** | 메인 페이지로 이동 |

#### 3.1.4 토큰 관리

| 토큰 유형 | 유효 기간 | 용도 |
|-----------|-----------|------|
| Access Token | 1분 | API 인증 |
| Refresh Token | 7일 | Access Token 갱신 |

**토큰 갱신 규칙:**
- Access Token 만료 시 Refresh Token으로 자동 갱신
- Refresh Token 만료 시 재로그인 필요
- 자동 로그인 미선택 시 세션 종료와 함께 토큰 만료

### 3.2 게시판 시스템

#### 3.2.1 게시판 구조

```
게시판 그룹 (CategoryGroup)
├── 카테고리 (Category)
│   ├── 서브 카테고리 (SubCategory) [선택]
│   └── 서브 카테고리 (SubCategory) [선택]
└── 카테고리 (Category)
    └── ...
```

#### 3.2.2 카테고리 속성

| 속성 | 설명 |
|------|------|
| **이름** | 카테고리 표시명 |
| **우선순위** | 정렬 순서 (낮을수록 먼저 표시) |
| **활성화 여부** | 비활성화된 카테고리는 노출되지 않음 |
| **익명 게시판 여부** | 해당 카테고리의 게시글/댓글 익명 처리 |
| **비공개 댓글 여부** | 해당 카테고리에서 비공개 댓글 기능 활성화 |

#### 3.2.3 게시글 기능

**게시글 작성:**

| 항목 | 필수 | 설명 |
|------|------|------|
| 제목 | ✓ | 게시글 제목 |
| 내용 | ✓ | 리치 텍스트 에디터 (HTML 지원) |
| 카테고리 | ✓ | 게시할 카테고리 선택 |
| 서브 카테고리 | ✗ | 서브 카테고리가 있는 경우 선택 |
| 이미지 | ✗ | 다중 이미지 업로드 가능 |
| 공지사항 | ✗ | 관리자만 설정 가능 |

**게시글 조회:**

| 기능 | 설명 |
|------|------|
| 목록 조회 | 카테고리별 게시글 목록 (페이지네이션) |
| 상세 조회 | 게시글 본문, 작성자, 작성일, 조회수, 좋아요/싫어요 수 |
| 공지사항 조회 | 목록 상단에 공지사항 별도 표시 |
| 인기 게시글 | 인기 게시글 별도 페이지 |
| 최근 게시글 | 메인 페이지에 카테고리별 최근 게시글 표시 (최대 3개 카테고리) |

**게시글 수정:**

| 항목 | 규칙 |
|------|------|
| 수정 권한 | 작성자 본인만 가능 |
| 수정 가능 항목 | 제목, 내용, 이미지 |
| 수정 불가 항목 | 카테고리, 서브카테고리 |

**게시글 삭제:**

| 항목 | 규칙 |
|------|------|
| 삭제 권한 | 작성자 본인 또는 관리자 |
| 삭제 방식 | 소프트 삭제 (DB에서 완전 삭제하지 않음) |

#### 3.2.4 조회수 규칙

| 규칙 | 설명 |
|------|------|
| 증가 조건 | 동일 세션에서 최초 조회 시에만 증가 |
| 중복 방지 | 세션 스토리지에 조회한 게시글 ID 저장 |
| 본인 글 | 본인 글 조회도 조회수 증가에 포함 |

#### 3.2.5 좋아요/싫어요

| 항목 | 규칙 |
|------|------|
| 대상 | 게시글, 댓글 |
| 동작 방식 | 토글 (다시 클릭하면 취소) |
| 중복 방지 | 한 사용자당 게시글/댓글별 1회만 가능 |
| 동시 선택 | 좋아요와 싫어요 동시 선택 가능 |

#### 3.2.6 신고 기능

| 항목 | 규칙 |
|------|------|
| 대상 | 게시글, 댓글 |
| 신고 사유 | 필수 입력 |
| 중복 신고 | 동일 사용자가 같은 대상 중복 신고 불가 |
| 신고 처리 | 관리자가 어드민 페이지에서 확인 및 처리 |

### 3.3 댓글 시스템

#### 3.3.1 댓글 구조

```
게시글
├── 댓글 1 (rootId: 1)
│   ├── 대댓글 1-1 (parentId: 1, rootId: 1)
│   └── 대댓글 1-2 (parentId: 1, rootId: 1)
├── 댓글 2 (rootId: 2)
└── 댓글 3 (rootId: 3)
    └── 대댓글 3-1 (parentId: 3, rootId: 3)
        └── 대대댓글 3-1-1 (parentId: 3-1, rootId: 3)
```

#### 3.3.2 댓글 기능

**댓글 작성:**

| 항목 | 규칙 |
|------|------|
| 내용 | 필수, 텍스트만 가능 |
| 대댓글 | 모든 댓글에 대댓글 작성 가능 |
| 대댓글 깊이 | 무제한 (UI에서는 들여쓰기로 표현) |

**댓글 조회:**

| 항목 | 규칙 |
|------|------|
| 정렬 순서 | rootId 오름차순 → id 오름차순 |
| 페이지네이션 | 기본 10개씩 |
| 기본 페이지 | 마지막 페이지 (최신 댓글 먼저 표시) |

**댓글 삭제:**

| 항목 | 규칙 |
|------|------|
| 삭제 권한 | 작성자 본인 또는 관리자 |
| 삭제 방식 | 소프트 삭제 |
| 대댓글 처리 | 부모 댓글 삭제 시 대댓글은 유지 |

#### 3.3.3 비공개 댓글

**활성화 조건:**
- 카테고리에 `isPrivateComment: true` 설정

**비공개 댓글 조회 규칙:**

| 사용자 유형 | 조회 가능 여부 |
|------------|---------------|
| 댓글 작성자 본인 | ✓ |
| 게시글 작성자 | ✓ |
| 슈퍼 관리자 | ✓ |
| 그 외 사용자 | ✗ ("비공개 댓글입니다" 표시) |

### 3.4 익명 시스템

#### 3.4.1 익명 게시판 규칙

**활성화 조건:**
- 카테고리에 `isAnonymous: true` 설정

**익명 ID 부여 규칙:**

| 규칙 | 설명 |
|------|------|
| 부여 시점 | 해당 게시글에 첫 활동(글/댓글) 시 |
| ID 형식 | "익명1", "익명2", ... |
| 유지 범위 | 동일 게시글 내에서만 동일 익명 ID 유지 |
| 게시글 작성자 | 다른 사용자와 동일하게 익명 ID 부여 |

**예시:**
```
게시글 작성자 A → "익명1"
첫 번째 댓글 작성자 B → "익명2"
두 번째 댓글 작성자 A → "익명1" (동일)
세 번째 댓글 작성자 C → "익명3"
```

#### 3.4.2 익명 시 표시 정보

| 항목 | 일반 게시판 | 익명 게시판 |
|------|------------|------------|
| 작성자 이름 | 닉네임 | 익명ID |
| 프로필 이미지 | 사용자 이미지 | 기본 이미지 |
| 작성자 링크 | 프로필 페이지 | 없음 |

|------|----------|----------|

**프로필 이미지 변경:**
- 새 이미지 업로드 시 기존 이미지 대체
- 이미지 삭제 기능 없음 (기본 이미지로 변경 불가)

## 5. 비즈니스 규칙

### 5.1 회원 관련 규칙

| 규칙 ID | 규칙 내용 |
|---------|----------|
| USR-001 | 카카오 계정당 하나의 서비스 계정만 생성 가능 |
| USR-002 | 닉네임은 서비스 전체에서 유일해야 함 |
| USR-003 | 탈퇴 기능 없음 (소프트 삭제만 지원) |
| USR-004 | 이메일, 실명, 전화번호는 수정 불가 (카카오 연동 데이터) |

### 5.2 게시글 관련 규칙

| 규칙 ID | 규칙 내용 |
|---------|----------|
| PST-001 | 게시글 작성은 로그인 필수 |
| PST-002 | 게시글 수정은 작성자 본인만 가능 |
| PST-003 | 게시글 삭제는 작성자 본인 또는 관리자만 가능 |
| PST-004 | 삭제된 게시글은 목록에 표시되지 않음 |
| PST-005 | 삭제된 게시글의 댓글도 함께 숨김 처리 |
| PST-006 | 카테고리 변경 불가 (작성 후) |
| PST-007 | 공지사항은 관리자만 작성 가능 |
| PST-008 | 공지사항은 목록 상단에 고정 표시 |

### 5.3 댓글 관련 규칙

| 규칙 ID | 규칙 내용 |
|---------|----------|
| CMT-001 | 댓글 작성은 로그인 필수 |
| CMT-002 | 댓글 수정 기능 없음 |
| CMT-003 | 댓글 삭제는 작성자 본인 또는 관리자만 가능 |
| CMT-004 | 부모 댓글 삭제 시 대댓글은 유지 |
| CMT-005 | 삭제된 댓글은 "삭제된 댓글입니다" 표시 |

### 5.4 익명 관련 규칙

| 규칙 ID | 규칙 내용 |
|---------|----------|
| ANO-001 | 익명 ID는 게시글 단위로 부여 |
| ANO-002 | 동일 사용자는 같은 게시글 내에서 동일 익명 ID 유지 |

| ANO-004 | 익명 게시판에서 작성자 프로필 클릭 불가 |
| ANO-005 | 관리자도 익명 게시판에서 실제 작성자 확인 불가 |

### 5.5 비공개 댓글 규칙
